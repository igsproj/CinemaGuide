Web приложение "CinemaGuide"<br>
Автор: Щербаков Игорь (is-inbox@yandex.ru)<br>

## ssh ##
git clone git@github.com:igsproj/CinemaGuide.git<br>

## https ##
git clone https://github.com/igsproj/CinemaGuide.git<br>

cd CinemaGuide<br>

Установка модулей<br>
npm i<br>
npm upgrade<br>

Запуск dev сервера<br>
npm run dev<br>

Сборка приложения<br>
npm run build<br>

Результат сборки будет в dist<br>
Запуск сборки: например serve -s (или любым другим http сервером как одностраничный сайт SPA)
